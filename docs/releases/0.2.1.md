# OFXR Bridge v0.2.1 (V116) — Compatibility Preview

This release focuses on improved compatibility and stability across more
OpenXR games and VR mods.

## What's improved

- Improved compatibility with UEVR.
- Added support for UEVR AFW configurations.
- Improved UEVR Native Stereo compatibility.
- Improved compatibility with Luke Ross VR mods.
- Improved SteamVR frame pacing and stability, especially at high headset
  resolutions and GPU loads.
- Improved handling of recentering, resolution changes and swapchain
  recreation.
- Improved support for games running with administrator privileges.
- Improved Arm, Disarm and tray shutdown cleanup, including stale
  registrations left by previous versions.

This is still an experimental pre-release and compatibility is not universal.
Please report both working and non-working games through
[GitHub Issues](https://github.com/tig3rmast3r/OFXR-Bridge/issues) or the
[Flat2VR Modding Discord](https://discord.gg/flat2vr), including an OFXR flight
log when available.
